# Scenario English

一套面向真实旅行沟通的**场景英语课程**。

目标不是考试，也不是按语法章节背知识点，而是通过真实场景训练，让学习者在英语环境中能够：**看得懂、听得懂、会回答、会确认、会解决问题**。

课程目前以英国旅行作为主要实践环境，同时优先选择在英语国家都能使用和理解的通用表达。

## 核心原则

1. **按真实场景学习，而不是按语法章节学习。**
2. 使用三层知识树：**主题 → 子主题 → 最小场景**。
3. 每个场景都对应一个可以完成的真实任务，例如“柜台值机”“酒店入住”“餐厅结账”“处理银行卡被拒”。
4. 英国英语为主要参考，同时覆盖通用英语；存在明显地区差异时标注 `UK / US / AU/NZ / General`。
5. 优先学习**高频、可迁移、能救场**的表达，再补充地区表达和更自然的说法。
6. 不只训练“我会说什么”，也重点训练**工作人员会说什么**以及如何听懂关键词。
7. 必须训练真实异常：延误、取消、预订错误、支付失败、听不清、找不到、丢失等。
8. 同一个高频句型应跨场景反复使用，不在每一课重新创造一套表达。
9. 学习目标是把事情办成，而不是把教材背完。

## 课程架构

课程分成两套互补结构：

### 1. Curriculum — 我可能会遇到什么

[`CURRICULUM.md`](./CURRICULUM.md) 保存完整旅行知识树和稳定 Scene ID。

它按照真实旅行过程覆盖：

- 机场与飞行
- 英国入境
- 城市交通
- 城际铁路与长途交通
- 酒店 / 民宿 / 青旅
- 餐厅 / 咖啡店 / Pub
- 购物与支付
- 景点与娱乐
- 电话、网络与日常服务
- 社交
- 医疗
- 安全与紧急情况
- 天气与户外
- 预订与客服
- 回程

### 2. Learning Path — 我应该先学什么

[`LEARNING_PATH.md`](./LEARNING_PATH.md) 不按照旅行发生顺序机械学习，而按照：

- 高频程度
- 生存价值
- 可迁移程度
- 对后续场景的支撑作用
- 出问题后的恢复能力

来安排学习顺序。

当前提供一条 **12 周核心学习路线**，用于先建立最常用的独立旅行沟通能力。

## 三种 Scene 类型

不是所有场景都应该写成一样重的课程。

### Core

高频核心任务，完整学习。

通常包含：

- 正常流程
- 高频工作人员输入
- 你需要主动说的表达
- 新词与复习词
- New / Review Patterns
- 正常流程角色扮演
- 异常角色扮演
- Pressure Test
- 练习与通关标准

### Exception

异常专项训练，例如：

- 行李超重
- 航班取消
- 酒店房型错误
- 银行卡被拒
- 行李未到

Exception 默认复用已有 Core 的词汇和句型，只补充解决异常需要的新内容。

### Extension

低频流程、地区差异、文化背景或特定旅行方式的扩展内容。

不是所有学习者都需要完成。

## Pattern Bank

[`PATTERN_BANK.md`](./PATTERN_BANK.md) 维护整个课程共用的高频可迁移句型。

例如：

```text
P001  I'd like to + action
P006  Do I need to + action?
P016  Did you say + information?
P019  Could you say that again?
P023  How much is + noun?
P033  There's a problem with + noun
P038  What are my options?
```

场景课会区分：

- **New Patterns**：本课真正新增的表达结构
- **Review Patterns**：以前学过、在新场景继续使用的结构

目标不是学几百套互不相关的“旅行句型”，而是把几十个真正高频的结构练到可以跨场景自然使用。

## 每个场景重点训练什么

### 你会看到什么

真实环境中的：

- Signs
- Screens
- Machines
- Menus
- Tickets
- Documents
- App / kiosk 提示

### 对方会说什么

重点收录工作人员真实高概率输入，并提供关键词抓手。

例如：

> **Are you checking any bags today?**  
> 抓关键词：`checking` + `bags`

### 你应该说什么

优先教简短、自然、能立即解决问题的英语，而不是复杂书面表达。

### 听不懂怎么办

Conversation repair 是课程核心能力之一：

- 请求重复
- 请求说慢一点
- 确认数字 / 时间 / 金额
- 确认关键词
- 请求换一种说法
- 请求写下来或指给你看

## Vocabulary 设计

词汇不再按“每课必须凑够多少个”来设计，而分成：

### New Vocabulary

本课需要主动掌握的新词。

### Review Vocabulary

之前学过，在当前场景继续使用。

### Recognition Vocabulary

真实环境中需要看懂或听懂，但不一定要求学习者主动说出的词。

这样可以避免不同 Scene 重复堆积相同词汇。

## Role Play 设计

Core Scene 通常分成三层训练：

### A. Normal

顺利完成正常任务。

### B. Problem

加入一个常见异常，并继续把事情办成。

### C. Pressure Test

模拟真实交流压力，例如：

- 对方语速更快
- 数字或时间变化
- 没听清
- 对方换一种表达
- 同时出现多个信息点
- 环境嘈杂

重点不是背完整对话，而是训练临场反应。

## 推荐学习方式

学习一个 Core Scene 时，可以分四步：

1. **Input** — 看懂标识、关键词和工作人员高频表达。
2. **Output** — 能自己完成核心请求和回答。
3. **Role Play** — 先正常流程，再加入异常。
4. **Pressure Test** — 不看中文提示，加入数字、时间、口音、没听清等干扰。

推荐使用间隔复习：

- **D0**：首次学习
- **D2**：两天后快速回忆
- **D7**：一周后加入新异常
- **D21**：三周后和其他场景混合训练

学习标准不是“我看过了”，而是：

> **遇到同类场景时，我能用现有英语继续交流，并最终把事情办成。**
